# СІЧ v0.9 — Telegram Mini App

## Что готово
- Новый работающий стартовый экран с кнопкой «ГРАТИ».
- Утверждённый стиль: зелёная крепость, золотая эмблема, цвета и слоган.
- Прежние механики v0.8 сохранены: строительство, Січ, дружина, бои, приключения, земли, достижения.
- Прежний ключ localStorage (`kozak_online_v3`) оставлен без изменений, чтобы не сбросить прогресс при обновлении по тому же URL/домену.
- Кнопка «☰ Меню» возвращает на заставку.

## Как открыть локально
Распаковать **всю папку** и открыть index.html в Chrome. Папка assets должна находиться рядом. Для размещения в Telegram загрузить весь состав папки на HTTPS-хостинг (например, GitHub Pages).

## Важно
- Сохранение пока **локальное**, на конкретном устройстве и origin. Оно не синхронизируется между устройствами. При переносе игры с `file://` на GitHub Pages сохранение автоматически не переносится.
- Это прототип; рейтинг, полноценная авторизация через сервер и платежи ещё не подключены.
- Не публиковать токен BotFather ни в HTML, ни в GitHub.
- После размещения BotFather: /setmenubutton → @SichGameBot → URL сайта → «⚔️ Грати».
