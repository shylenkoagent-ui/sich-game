СІЧ v4.4 — Майдан дружини

Козаки більше не патрулюють: стоять на окремому майдані біля центрального двору. Їхня кількість залежить від найму. Деякі тримають люльки з декоративним димом, є легка анімація стійки. Отаман самостійно рухається дорогами, а над ним постійно сяє золота зірка.

Тестова збірка: Telegram та хмарні збереження не перемикати до перевірки.
